Frequently Asked Questions

1. What is ZPA?

ZPA (Zeichnungsprüfung Automation) is an automated drawing inspection system that analyzes engineering drawings and validates them against VW standards and KVS data. It helps identify errors and compliance issues before release.

2. What file formats are supported?

Supported formats:

  • PDF (single-page and multi-page)
  • TIFF (single-page and multi-page)

Not supported:

  • JPG, PNG, BMP, GIF
  • Word documents, Excel files
  • Native CAD files

CAD files should be exported to PDF or TIFF before processing.

3. How does ZPA work?

The process includes:

  1. User submits a drawing.
  2. ZPA creates a processing task.
  3. KVS data is retrieved.
  4. Drawing is processed.
  5. OCR extracts information.
  6. Validation rules are executed.
  7. Results are aggregated.
  8. Inspection report is generated.

4. What statuses can an inspection have?

Common statuses:

  • CREATED
  • SCHEDULED
  • RUNNING
  • COMPLETE
  • FAILED

Users can monitor the current status through the dashboard.
